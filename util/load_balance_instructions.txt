load balance freecount:

Spin up a set of instances to act as worker VMs using the image called freeCount.
Make a list of the IPs associated with the servers, i.e.:
   149.165.170.240
   149.165.170.241
   149.165.170.242

Spin up instance to act as front end machine using image called Load Balance freeCount
Note the IP for the front machine, i.e. 149.165.170.24.
Upon instance start, open web shell

cd /etc/nginx/sites-enabled/
sudo nano default

Uncomment the section under Default server configuration, starting with "upstream classpool {", and ending with the end of that code block.
Add the IPs from your list you made above to this block, so that it reads similarly to:

upstream classpool {
    ip_hash;
    server 149.165.170.240:3838;
    server 149.165.170.241:3838;
    server 149.165.170.242:3838;
}

scroll down to the lines that says "server name 149.165.174.11;" and replace that IP with your front machine's IP.

Uncomment the tools you wish to use the workers to load balance.  For example, if you wish to use SO, uncomment:
#        location /SO/ {
#            client_max_body_size 500M;
#            proxy_pass http://classpool/freeCount/SO/;
#        }

save and exit

Restart nginx with the following command:
sudo systemctl restart nginx

Check to make sure it loaded properly with:
sudo systemctl status nginx
